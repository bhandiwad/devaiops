# Tenant Admin Guide

- Use Backstage Onboarding Wizard for BYOC or PROVISIONED tenant creation
- Track progress in onboarding status and audit timeline

## Products
- View marketplace products
- Enable/disable with policy and approval gates
- Verify module/capability requirements before enabling

- Submit access requests
- Approve/deny as tenant admin
- Review audit and policy decision records

## Deployments and incidents
- Use Deployments page for sync/rollback guidance
- Use Incidents page for evidence -> investigate -> PR workflow
